# Design Consultation

## Requirements

- Use a browser or another renderer for a live preview. Use an image or design tool when mockup generation is requested.

## Procedure

1. Read the product brief and any existing tokens. Describe the audience, the first impression they should remember, and the interactions the system needs to support.
2. When research is in scope, inspect comparable products and identify useful conventions and room for a distinctive direction. Verify fonts and their licenses using available local or authoritative evidence.
3. Propose a coherent design system covering roles for color and type, spacing, layout, components, states, and motion. Demonstrate contrast, responsive behavior, and the system's application to a representative screen.
4. Capture feedback on a rendered preview or approved mockup. Save the decisions, token sources, accessibility guidance, and examples in DESIGN.md. Label unverified assets or font choices as pending.
