# Project Learnings

## Procedure

1. Resolve the requested mode and project. Search entries by key and type, and check cited evidence before reporting the latest supported learning.
2. For additions, record the durable lesson, its trigger and evidence. Avoid secrets and one-off inferences. Export only the requested scope.
3. For pruning, identify stale paths and contradictory evidence. Apply only the requested keep, replace or remove action. Leave product code untouched.
