# Design Shotgun

## Requirements

- Use a design, image generation, or HTML preview tool capable of producing comparable variants.

## Procedure

1. Read the brief, approved constraints, existing design system, and any user preferences. Capture the current screen once if the request is to evolve it.
2. Describe several directions with different visual concepts or layout archetypes. Keep the content, task, and comparison viewport stable across candidates so feedback identifies the design decision.
3. Generate one representative design per direction with an available design, image, or HTML tool. Present a lettered comparison board with the actual renders.
4. Ask for specific feedback about what to retain or change, then iterate on the directions the user wants to explore. Keep each round's candidates and feedback associated with that round.
5. Write an approval artifact for the exact accepted variant. Include its image or preview path, any chosen archetype and section order, and the instructions that carry into implementation.
