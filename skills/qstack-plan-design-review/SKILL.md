# Plan Design Review

## Procedure

1. Read the selected plan, design tokens, prior decisions, and current product. Identify the key screens, user journeys, and the states the proposal needs to describe.
2. Rate information hierarchy, typography, spacing, visual direction, interaction and feedback, responsive behavior, and accessibility on a 0-to-10 scale. Explain the observable difference between the current proposal and a high-scoring version.
3. For each unresolved material gap, present the affected screen or interaction and plausible designs. Use a sketch or side-by-side mockup when it makes the decision clearer. Preserve settled design decisions where the evidence still supports them.
4. Update the agreed plan and affected tokens together. Re-rate changed dimensions and record each unresolved issue as a decision or an implementation risk.
