# Diagram

## Requirements

- Use a Mermaid renderer and an Excalidraw-compatible converter.

## Procedure

1. Choose a flowchart for relationships and a sequence diagram for interaction order. Use named entities, directional edges, and labels that communicate the user's requested relationships.
2. Save the Mermaid source. Verify the source renders and convert supported shapes and text to editable Excalidraw elements. Record any diagram type that must use an embedded image for fidelity.
3. Render SVG and PNG from the same source or scene. Open the rendered output and check legibility, clipping, and correspondence with the original request.
4. Deliver the Mermaid, Excalidraw, SVG, and PNG paths. Use the source or editable drawing for subsequent changes.
