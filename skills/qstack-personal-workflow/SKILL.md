# Personal Workflow

## Procedure

1. Identify the user's desired workflow or style and inspect the named skill if it exists. Ask for examples only when an important preference cannot be grounded.
2. Extract durable non-default preferences from user examples and specifically authorized records. Separate recurring patterns from one-off corrections and contradictions.
3. Draft concise trigger-specific instructions in a portable skill format. Reference existing procedures where appropriate and check the result against representative examples before saving.
