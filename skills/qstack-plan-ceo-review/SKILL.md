# Plan Ceo Review

## Procedure

1. Pin the plan or diff under review. Restate the user problem and the cost of leaving it unsolved. Map the proposal to reusable parts of the existing product and a concrete longer-term ideal.
2. Honor the user's scope mode. When it is open, use the plan and available evidence to recommend expansion, selective expansion, hold, or reduction. Distinguish a recommendation from an adopted scope change.
3. In expansion, look for much larger user value and small adjacent improvements. In selective expansion, consider each addition separately. In hold, improve completeness within the current boundary. In reduction, identify the smallest deliverable that still solves the problem.
4. Walk the plan through foundation, implementation, integration, deployment, and the first weeks after launch. Identify choices with user impact and failures that would invalidate the plan.
5. Record the vision, accepted scope, deferred items, and remaining blockers in the reviewed plan. Keep unapproved options visible for the next decision.
