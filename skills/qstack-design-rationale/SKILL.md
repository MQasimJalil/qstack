# Design Rationale

## Procedure

1. Locate when the relevant choice entered the project, then read the introduction and subsequent changes in commits, reviews, issues, or design records.
2. Trace the reason the authors gave, the tradeoffs they considered, and any later change to the decision. Link to the original evidence.
3. State what the record establishes and mark any inference as such. Identify the question the available record leaves unanswered.

## Upstream sources
