# Unslop

## Procedure

1. Read the text and intended audience. Preserve verified claims, names, qualifiers, and the author's purpose.
2. Cut ornamental framing, unsupported praise, empty conclusions, generic jargon, and repetition. Replace vague descriptions with the mechanism or evidence they refer to.
3. Use active verbs, direct sentence structure, and consistent terminology. Unpack dense clauses, vary rhythm so it reads naturally, and preserve formatting that helps the reader act.
4. Review the revised text line by line for any weakened claim, ambiguity, or added assumption. Return the edited copy in the requested format.
