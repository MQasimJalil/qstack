# Sharpen

## Procedure

1. Identify what an expert would do within the existing project's scope that the brief misses.
2. Name the most direct evidence, concrete methods, tools, and independent signal that would establish a correct result.
3. Split choices a prototype or experiment can settle from preference and strategy decisions that belong to the user.
4. Return a rewritten prompt with the same outcome, a stronger method, and observable completion criteria.
