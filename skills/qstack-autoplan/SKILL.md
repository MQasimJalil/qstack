# Autoplan

## Procedure

1. Load the current plan and freeze a restorable copy. Record the user objective, scope, unresolved decisions, and known evidence in one decision log.
2. Apply the strategy or scope lens once. Apply design only to user-facing changes and developer experience only where developers have a changed path. Carry accepted edits forward after each pass.
3. Use qstack-plan for the final engineering review. If the user requests independent review and the host supports it, provide the frozen plan and the same decision rubric to an independent reviewer.
4. Accept the revised plan when the findings are resolved and selected checks apply to the final version. Keep product or externally consequential choices with the user when approval is required.
