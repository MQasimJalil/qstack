# Proceed Within Scope

## Procedure

1. Distinguish a factual uncertainty you can observe from a product choice or genuine approval. Run the smallest safe check for factual uncertainty.
2. Proceed with a reasonable, reversible decision inside the user’s request. Record a material assumption and verify the result so the user can correct it from evidence.
3. Keep working on independent authorized steps when a decision is genuinely needed. Respect named checkpoints and required authorization for external or irreversible actions.
