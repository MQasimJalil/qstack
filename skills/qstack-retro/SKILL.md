# Retro

## Procedure

1. Resolve scope, dates and user timezone. For comparison, use an immediately preceding equal window with the same filters. Include other projects only for the requested cross-project view.
2. Gather commits, reviews, PRs and releases from available records. Deduplicate by repository and identity. State any missing sources or incomplete observations.
3. Summarize delivered outcomes, unfinished work, recurring friction, and meaningful movement in comparable measures. Point to concrete evidence and avoid drawing productivity conclusions from commit counts alone.
