# Arena

## Procedure

1. Define the artifact and a private rubric of three to six observable criteria. Give every candidate the same brief, shared evidence, and a separate output directory or worktree.
2. Run candidates independently through authorized host delegation when available. In a host without delegation, compare distinct alternatives serially and record that independent judgment was unavailable.
3. Read every viable candidate. Score it against the rubric and capture what its rationale considered. Use a separate read-only judge from an available different model family when useful.
4. Choose the easiest sound base to maintain. Integrate only improvements that fit its design. Keep the consensus shape when candidates agree, or tighten an ambiguous brief when they diverge without a defensible winner.
5. Verify the final artifact directly and record the rubric, selected base, useful grafts, rejected alternatives, and any missing candidate or independent judge.
